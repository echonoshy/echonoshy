### [映芽 · Yingya](https://github.com/echonoshy/yingya)

以对话承接灵感，以影像呈现所想。围绕资料与素材，完成方案构思、关键画面预览与视频生成；支持截图及时间点反馈、链接分享和 MP4 导出。
