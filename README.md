## 最近在做

### [映芽 · Yingya](https://github.com/echonoshy/yingya)

通过对话，把资料、想法和已有素材做成可以直接分享的视频。先看方案和关键画面，再用截图或时间点提出修改，最后分享链接或导出 MP4。

最近更新到 **0.4.0**，打磨了创作首页、作品目录和视频制作内核。
