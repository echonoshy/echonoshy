## 项目

### 创作与日常应用

**[映芽 Yingya](https://github.com/echonoshy/yingya)** · 视频创作\
把文章、产品截图或录屏做成短片。先确认分镜和关键画面，再生成配音与字幕。看过初稿后，可以截一张图或指定时间点，让映芽重做那个镜头。[在线创作](https://yingya.art/) · [观看演示](https://youtu.be/DuEsvIO0zt4)

**[open-fitness](https://github.com/echonoshy/open-fitness)** · 桌面健身教练\
练深蹲或俯卧撑时，电脑摄像头会在本机识别动作并计次。可以用语音把下一组改成十次，练完再回看每组的次数和动作反馈。[68 秒演示](https://echonoshy.github.io/open-fitness/#demo) · [下载桌面版](https://github.com/echonoshy/open-fitness/releases/latest)

**[D.VA](https://github.com/echonoshy/d.va)** · 多人播客\
从几个关键词开始，把一个话题做成多人对谈的播客。可以给不同说话人选音色，再加上片头、片尾和背景音乐。仓库里有一期成品可以试听。

**[听舒 Tingshu](https://github.com/echonoshy/tingshu)** · 有声书\
用语音合成把书稿逐章转成音频。网页书架里可以试听《小米创业思考》，从前言开始听，也可以直接跳到感兴趣的一章。[打开书架](https://echonoshy.github.io/tingshu/web/)

### Agent 与实时语音

**[Ripple](https://github.com/echonoshy/ripple)** · 跨设备的 Codex 工作空间\
在电脑上开始一个会话，换到手机也能接着处理同一项任务。会话、项目文件和任务记录放在同一处，还可以接入飞书等服务。[查看界面](https://echonoshy.github.io/ripple/)

**[Ripple Live](https://github.com/echonoshy/ripple-live)** · Android 语音助手\
打开摄像头就能围绕眼前的东西提问，也能在助手回答时插话。聊到要做的事，可以直接让它建一条待办，之后从会话历史里找回当时的上下文。

**[mic-on](https://github.com/echonoshy/mic-on)** · 穿戴式语音终端\
把 GPT-Live 接到一台 ESP32 小设备上。按键可以录一段话再发送，也可以切到持续对话模式，连上 Wi-Fi 就能直接开口聊。

**[Replica](https://github.com/echonoshy/replica)** · 跨会话记忆\
从聊天记录中提取事实、偏好和计划。下次对话提到相关话题时，用关键词和向量检索找回对应的记忆，让助手接着上次的内容聊。

### 教程、实验与数据

**[cgft-llm](https://github.com/echonoshy/cgft-llm)** · 动手做大模型\
一套配有中文视频和示例代码的实战教程。可以从本地部署、微调模型开始，再用自己的文档搭一个 RAG 知识库，或跟着案例做一个 AI 播客。

**[FloodNet Segmentation](https://github.com/echonoshy/floodnet-segmentation)** · 洪灾航拍图分割\
在同一批航拍图上比较 UNet、PSPNet 和 DeepLab。除了看测试指标，还可以把原图、人工标注和三个模型的预测并排看，找出它们在哪些区域判断不同。

**[cn-market-daily](https://github.com/echonoshy/cn-market-daily)** · 沪市每日数据\
按日期把上交所的成交统计存成 JSON。打开某一天的文件，就能查看主板 A 股、科创板等板块的成交额、市值和换手率，也方便取几天的数据做对比。

**[非线性回报](https://github.com/echonoshy/nonlinear-returns)** · 关于收入与工作的系列图解\
从「为什么很多人努力，却不富有」这个问题出发，把劳动如何定价、AI 怎样改变技能的价值拆成几期来讲。第一期用两条曲线对照按时间获得的收入和逐步累积的回报。
