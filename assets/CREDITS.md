# Cloud Express — echonoshy

A silent, 10-second looping banner adapted for this GitHub profile with Remotion and WebGL. The personal wordmark is text only.

The cloud, bridge and train shader is adapted from [Up in the Cloud Sea](https://people.tamu.edu/~choutianxius/csce646/pr01/index.html) by Tianxiu (Tyson) Zhou, whose source credits [mdb's ShaderToy work](https://www.shadertoy.com/view/Ndc3zl).

Upstream source: [choutianxius/csce646-digital-image](https://github.com/choutianxius/csce646-digital-image). Its MIT notice is retained in [cloud-shader-MIT.txt](cloud-shader-MIT.txt).

This edition adds frame-based timing, an echonoshy wordmark, a profile-banner layout, exposure adjustment and a loop crossfade. It does not imply endorsement by the original authors. No audio from the reference video is included.

- `cloud-express.gif`: animated profile header.
- `cloud-express.png`: static alternative for reduced-motion preferences.
